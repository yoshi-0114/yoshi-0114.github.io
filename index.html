1. コマンドプロンプト上で動作するテトリスの制作

概要
使用言語：C++
プログラム：WindowsとLinuxのテトリスのコード
まず，Windows環境でコマンドプロンプトで動作するテトリスを制作し，それをもとにLinuxのターミナルで動作するように変更した．
将来的には，本作のアルゴリズムをもとにUnityでの制作も考えている．

行う処理の説明
  1. ランダムにミノと呼ばれるブロックをランダムに出力し，一定以上の時間が経過すると降下．
  2. キーボードでのw,a,s,dでミノを移動し，その他のキーで回転．
  3. 移動する際は，出力を消去し，新しく出力するような更新作業を行う．
  4. ミノが一番上まで上がった際はGAME OVERと出力．

プログラムの説明
  1. ミノは配列を用いて描画し，ランダムに出力．
  2. キーボード入力は，_getch()を用いて判別．(Linuxの場合getch())
  3. 移動する際の出力の消去は，system()を用いて出力をクリアするコマンドの「cls」を実行し，移動後を出力．(Linuxの場合「clear」)
  4. ミノは配列で処理しているので，一番上までミノが到達しているかどうかを「1」の際に確認して，到達していたらGAME OVERと消した行数(Score)を出力してreturn 0を返す．

2. 赤外線距離センサで障害物を避けるロボットカーの制作

概要
開発環境：Arduino IDE(C++)
プログラム：ロボットカーとセンサのコード
Arduinoマイコンを用いて，制作したプログラムをモーターに組み込んで動作させる．
下の画像のようなロボットカー2機をコの字型コースを走らせタイムを計る．

プログラムを組む前に事前に使用するセンサが正しく動作するかの測定実験を行い，正しく動作する数値を記録する必要がある．
その際に使用するプログラムをgithub上のsensor.inoに示す．

行う処理の説明
センサは斜め前(左右)と前方向に配置してある．
斜め前方向のセンサで左右の距離を保ち，前のセンサで一定距離まで到達すると停止→回転→直進するプログラムを作成する．
直進するスピードを速くしすぎると，センサの反応が間に合わず，壁に衝突してしまうことがあるので注意が必要だった．

プログラムの説明
  1. 初期設定を行い，スイッチが押されるまで角速度センサを更新してLED制御を行う．
  2. ループ関数内では最初にモーターの速度を設定するための変数を定義し，赤外線距離センサの値を読み取る．
  3. 角速度センサを更新し，左もしくは右の赤外線距離センサの値を読み込み基準角速度を計算．
  4. 計算した基準角速度と実際の角速度の差を用いてモーターの速度を調整し，モーターを動かす．

3. デプスカメラで障害物を避け，自動で充電するTurtlebot2の制作

概要
開発環境：Linux・ROS(Python3)
プログラム：Turtlebot2を動作させるコード
Turtlebot2というロボット掃除機に土台とカメラを取り付けたロボットを使用する．
PCを土台の上に置き，コードを繋げてプログラム通りに操作をさせる．
デプスカメラを用いて障害物を避ける．
充電器からの赤外線を受信し，充電器とドッキングする．

下準備
ROSを利用するため，下記の作業をこれらを行う必要がある．
  1. ROSをインストール．
  2. catkin_makeでのビルド．
  3. ROSに関連する環境変数にsetup.bashを用いてワークスペースのパスを追加．
  4. catkin_create_pkgでのパッケージの作成．

行う処理の説明
デプスカメラを用いて障害物との距離を測定し，一定の距離まで接近したら，停止→回転→直進を行う．
今回は充電器の場所とそれまでの壁の数が分かっていたので，if()を使って指定回数曲がったら充電器とドッキングするプログラムを呼び出す．
ドッキングの際は，赤外線を探知できるようにある程度後退する．

プログラムの説明
  1. ROSノードを初期化し，速度指令を'/cmd_vel_mux/input/teleop'トピックに送信するためのパブリッシャーを設定．
  2. 'camera/depth/image_raw'トピックから深度画像を取得し，特定領域の平均深度を計算．
  3. 平均深度がしきい値以上の場合，ロボットを直進．
  4. 平均深度がしきい値未満の場合，ロボットを回転させて障害物を回避し，指定回数回転後にドッキングプログラムを起動．
  5. Twistメッセージを使用して，ロボットの直進と回転の速度指令を設定し，指定回数だけパブリッシュ．
  6. ROSノードを初期化し，メインの実行ループでロボットの動作を開始．

4. 音声・映像認識によるじゃんけんシミュレーションの制作

概要
使用言語：Python2.7，Python3
プログラム：音声認識によるじゃんけんシミュレーションのコード
映像認識によるじゃんけんシミュレーションのコード
音声または手の形に基づいてChoregraphe内のNaoqiとじゃんけんを行う．
音声・映像認識はPython3，Choregrapheの制御はPython2.7で行う．
Naoqiのじゃんけんの手はランダムで出し，自分の手と比較して勝敗を判定する．

行う処理の説明
  1. 音声または手の形から「グー」「チョキ」「パー」を判定し，判定結果をtxtファイルに書き出す．
  2. Naoqiの手と自分の手を比較し，勝敗を判定する．
  3. じゃんけんの結果に基づいて，Naoqiがリアクションを行う．

プログラムの説明
  1. じゃんけんの手を認識．
    • 音声認識：google speech-to-text APIを用いて音声を認識し，「グー」「チョキ」「パー」を判定．
    • 映像認識：手の特徴点から形を認識し，「グー」「チョキ」「パー」を判定．
  2. Naoqiがランダムに「グー」「チョキ」「パー」の手を選び、対応するジェスチャーを実行．
  3. Naoqiの手とユーザーの手を比較して，勝敗を判定．
  4. 勝敗に応じたリアクションをNaoqiがし，感情表現を行う．
  5. 引き分けの際は，1~4を再度実行．
音声認識のプログラムを実行する際は，以下のコマンドを実行する．
python3 .\hand.py
python3 .\hand_decide.py
映像認識のプログラムを実行する際は，以下のコマンドを実行する．
python3 .\audio_decide.py

5. メール内容保存および本文要約システムの制作

概要
使用言語：Python3
プログラム：メール内容保存および本文要約システムのコード
メール内容をMySQLに保存し，WEB上に表示する．
また，メールの本文を要約し，要約結果を保存する．

行う処理の説明
メールをIMAPで取得し，件名，送信者，受信日時，本文などに分割してデータベースに保存．
保存したデータはWEB上に表示され，CSVへの保存も可能．
新規メールアドレスからのメールの場合は，ハイライト表示．

プログラムの説明
  1. メールアドレスとパスワードを入力すると，IMAPを使用して指定されたメールアカウントに接続し，新着メールや既存メールを取得．
  2. MySQLデータベースに接続し，取得したメールデータを保存．
  3. Google Gemini APIやLexRankアルゴリズムを使用し，メール本文の要約を生成．
  4. 左側のメールを選択すると，右側に本文を表示．
  5. メール本文からメールアドレスやステータスを取得し，データベースに保存．
  6. 別のタブで、データベースの内容を5分ごとに自動更新して表示．
